# zcode-repo-wiki

ZCode 本地插件「repo-wiki」的源仓库：纯本地 Repo Wiki（零上传、零网络），替代 3.14.0 起被下架的官方 Repo Wiki 入口。

- 插件本体：[`repo-wiki/`](./repo-wiki/)（含 SKILL.md、/repo-wiki 命令、build_wiki_site.py 构建器、内联 mermaid 11）
- 安装/升级：`bash install.sh`（同步到 zcode 插件缓存 local 市场并启用；脚本为 bash 实现，`zsh install.sh` 亦可运行）
- 详情见 [repo-wiki/README.md](./repo-wiki/README.md)
